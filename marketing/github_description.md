**Repository name:** DocuCraft-PDF-Editor

**Short description (≤350 chars):**
Free, offline PDF reader, editor and PDF-to-Word converter for desktop. Annotate, redact (verified), merge, split, compress, OCR and protect PDFs — no uploads, no telemetry. Python · PySide6 · PyMuPDF.
