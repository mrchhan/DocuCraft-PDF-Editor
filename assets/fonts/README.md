# Bundled fonts

Used only to re-create text that DocuCraft replaces in a PDF when the document's own font cannot be reused.
All are open fonts under the SIL Open Font License 1.1 (full text and copyright holders in `licenses/`):

| Family | Copyright / source | Licence |
|---|---|---|
| Inter | The Inter Project Authors (rsms/inter) | OFL-1.1 |
| Poppins | Indian Type Foundry (Google Fonts) | OFL-1.1 |
| Liberation Sans / Serif / Mono | Red Hat, Inc. (metric-compatible with Arial / Times New Roman / Courier New) | OFL-1.1 |
| Carlito | tyPoland Lukasz Dziedzic (metric-compatible with Calibri) | OFL-1.1 |

The OFL text is reproduced in `licenses/fonts-inter.copyright.txt`. The fonts are not sold on their own and keep their original names.
