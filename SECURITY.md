# Security and privacy

- DocuCraft runs entirely on your computer. There are no accounts, no telemetry and no uploads. The only network action is opening the project's releases page in your browser when you click "Check for updates".
- Passwords are used in memory only and are never written to logs, settings or history.
- History stores file names, folders and page positions only - never document contents. You can turn it off or clear it in Settings.
- Redaction removes content from the file (verified after the fact); a black rectangle is never used as a substitute.
- Documents are validated (type, size, header) before opening, and temporary files live in a private folder that is cleaned on exit.

DocuCraft has not had an independent security audit. Please do not use it as the only safeguard for highly sensitive material.

## Reporting a vulnerability
Please open a **private** security advisory on the GitHub repository (Security tab -> Report a vulnerability) rather than a public issue.
